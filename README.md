# HSdeck 레거시 카드 API

Legacy 카드별 원본은 `data/<카드ID>.json`의 **한국 날짜별 키**로 관리합니다. 첫 기록에는 확보된 최초 스펙, 이후에는 변경된 필드만 저장합니다. 기존 카드 ID, 파일 경로, 원화와 관계 정보는 보존합니다. 다른 확장팩은 변경하지 않습니다.

- `data/`: 날짜별 카드 상태. 필드 삭제는 `__remove`로 명시합니다.
- `metadata/`: 출시일 신뢰도, 미확정 기록, 원본 증거, 현재 메타데이터와 관계/원화 연결. 추정일은 검증일로 승격하지 않습니다.
- `cards.json`: 기존 플러그인용 호환 현재 목록. 현재 616개 ID와 현행 입력값을 모두 유지합니다.
- `render.json`: 기존 플러그인용 현재 카드와 날짜별 호환 이력.
- `history.json`: WordPress가 사용하는 기존 형식 호환 이력. 실제 7.12.14도 요청하므로 유지합니다.
- `cards-date.json`, `render-date.json`, `history-date.json`: 속성 부재·삭제와 유형별 스탯을 정확히 표현하는 별도 신규 출력. 기존 플러그인의 연결 주소는 변경하지 않습니다.
- `art/`, `golden/`: 기존 원화/황금 원화 연결. 변경하지 않습니다.

형식, 미확정 날짜의 안전한 처리, 기본 호환 조회, 유형별 스탯, 빌드/검증 명령은 [날짜 스키마 문서](docs/date-schema.md)를 참고하세요.

**검증 한계:** 출처 파일의 현재 616개 ID 중 144건은 출시일 검증, 472건은 기존 추정값 보존입니다. 최초 스펙 전체가 검증됐다는 뜻은 아닙니다. 두 역사적 토큰의 원본 및 식별 증거는 메타데이터에 보존합니다. 한때 2013년으로 앞당겨졌던 강화 영웅 능력 11개, 판드랄의 합체 토큰 `OG_044a`, 핵심 세트에서 편입된 죽음의 기사 카드 18개 및 성전사의 오라를 실제 첫 사용일로 정정하고 잘못된 선행 키를 삭제했습니다. 2024-03-12 한국 29.0 패치 때 실제로 소환되기 시작한 은빛 성기사단 신병 신규 외형 6종은 2013년 가짜 최초 기록을 삭제했습니다. 드레나이 외형 `CS2_101t6` 역시 다른 신병 외형과 같은 2024-03-12에 처음 사용 가능했고, 드레나이 종족 도입 직전에 실제 소환 목록에서 제외되었습니다. 제거 날짜는 북미 2024-03-11 패치 후 공개된 비교 게시물을 근거로 한국 기준 **2024-03-12(잠정)**로 기록했으며, 같은 날의 추가·제거 순서나 시간은 미확정입니다. 2024-10-30 클라이언트 종족값은 게임플레이 이력에 소급하지 않습니다. 워크래프트 럼블 무료 핵심 세트 카드 `TOY_100`~`TOY_103`은 확장팩 출시 2024-03-20이 아니라 패치 즉시 사용일 2024-03-12로 정정했습니다. 설치된 최신 `nativeTags`를 과거에 소급하지 않습니다.

**호환성:** 플러그인 변경은 보류했습니다. 기존 세 주소에는 기존 소비자용 투영값을 생성하고, 정확한 신규 상태는 `-date` 출력에 분리합니다. 숫자 부재를 0으로 나타내는 등의 구형 한계는 호환 출력에만 남으며 원본에 소급하지 않습니다. 이번 변경의 범위는 API 자료 제공이며, 플러그인 설치·연결 주소 변경·실제 재가져오기·DB 변경은 수행하지 않습니다.

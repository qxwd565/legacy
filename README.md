# HSdeck 레거시 카드 API

Legacy 카드별 원본은 `data/<카드ID>.json`의 **한국 날짜별 키**로 관리합니다. 첫 기록에는 확보된 최초 스펙, 이후에는 변경된 필드만 저장합니다. 기존 카드 ID, 파일 경로, 원화와 관계 정보는 보존합니다. 다른 확장팩은 변경하지 않습니다.

- `data/`: 날짜별 카드 상태. 필드 삭제는 `__remove`로 명시합니다.
- `metadata/`: 출시일 신뢰도, 미확정 기록, 원본 증거, 현재 메타데이터와 관계/원화 연결. 추정일은 검증일로 승격하지 않습니다.
- `cards.json`: 기존 플러그인용 호환 현재 목록. 현재 615개 ID와 현행 입력값을 유지합니다. 스킨 외형 전용 영웅 능력은 공개 API 목록에서 제외합니다.
- `render.json`: 기존 플러그인용 현재 카드와 날짜별 호환 이력.
- `history.json`: WordPress가 사용하는 기존 형식 호환 이력. 실제 7.12.14도 요청하므로 유지합니다.
- `cards-date.json`, `render-date.json`, `history-date.json`: 속성 부재·삭제와 유형별 스탯을 정확히 표현하는 별도 신규 출력. 기존 플러그인의 연결 주소는 변경하지 않습니다.
- `art/`, `golden/`: 기존 카드 원화/황금 원화 연결을 유지하며, 공개 API에서 제거한 스킨 전용 영웅 능력의 단독 리소스는 삭제합니다.

형식, 미확정 날짜의 안전한 처리, 기본 호환 조회, 유형별 스탯, 빌드/검증 명령은 [날짜 스키마 문서](docs/date-schema.md)를 참고하세요.

**검증 한계:** 출처 파일의 현재 615개 ID 중 614건은 출시일 검증, 1건은 기존 추정값 보존입니다. 최초 스펙 전체가 검증됐다는 뜻은 아닙니다. 두 역사적 토큰의 원본 및 식별 증거는 메타데이터에 보존합니다. 한때 2013년으로 앞당겨졌던 강화 영웅 능력 11개, 판드랄의 합체 토큰 `OG_044a`, 핵심 세트에서 편입된 죽음의 기사 카드 18개 및 성전사의 오라를 실제 첫 사용일로 정정하고 잘못된 선행 키를 삭제했습니다. 2024-03-12 한국 29.0 패치 때 실제로 소환되기 시작한 은빛 성기사단 신병 신규 외형 6종은 2013년 가짜 최초 기록을 삭제했습니다. 드레나이 외형 `CS2_101t6` 역시 다른 신병 외형과 같은 2024-03-12에 처음 사용 가능했고, 드레나이 종족 도입 직전에 실제 소환 목록에서 제외되었습니다. 제거 날짜는 북미 2024-03-11 패치 후 공개된 비교 게시물을 근거로 한국 기준 **2024-03-12(잠정)**로 기록했으며, 같은 날의 추가·제거 순서나 시간은 미확정입니다. 2024-10-30 클라이언트 종족값은 게임플레이 이력에 소급하지 않습니다. 워크래프트 럼블 무료 핵심 세트 카드 `TOY_100`~`TOY_103`은 확장팩 출시 2024-03-20이 아니라 패치 즉시 사용일 2024-03-12로 정정했습니다. 2013년 북미 베타 첫 실사용일(한국 기준 2013-08-17)이 확인된 겔빈 멕카토크(`EX1_112`)와 발명품 토큰 5종(`Mekka1`~`Mekka4t`)은 날짜는 유지하고 최초 사용일 검증 상태만 승격했습니다. 베타 이전에 보상 세트에 있던 늙은 거먹눈 멀록(`EX1_062`)과 선장의 앵무새(`NEW1_016`)도 보상 퀘스트의 베타 최초 사용 가능일을 검증해 기존 2013-08-17을 유지했습니다. 9개 초기 직업의 기본 영웅 능력(`HERO_01bp`~`HERO_09bp`) 역시 첫 북미 베타 실사용일의 한국 날짜인 2013-08-17로 기존 날짜를 유지하면서 검증 완료 처리했습니다. 전사 기본 영웅 능력(`HERO_01bp`, DBF 725)은 게임플레이 기준 2013-08-17을 유지하며 초기 원본 ID `CS2_102`에서 2020년 변경된 이력을 별도로 명시했습니다. 스킨 전용 복제 영웅 능력 ID와 그 카드 JSON·원화·황금 카드 JSON은 공개 고전 API에서 삭제하고 기본 영웅 능력과 효과가 다른 강화 능력은 보존했습니다.  2013년 8월 16일(북미) 실시간 베타 3664 덱 목록에 등장한 수집 가능 카드 27장은 한국 시간 2013-08-17 최초 사용을 검증했습니다. 과거 카드 스탯의 정확성은 별도 검증 대상입니다.  2013년 첫 베타 사제·사냥꾼 덱에 직접 기재된 수집 가능 카드 45장도 동일한 최초 한국 사용일을 교차검증했습니다.  드루이드·주술사·성기사·흑마법사·도적의 2013년 베타 첫날 덱에 수록된 카드 63장도 당시 실사용 날짜를 검증했습니다.  2013년 베타에서 처음부터 사용된 수집 가능 카드가 생성하던 자식 카드 ID 26개를 당시 부모 효과·클라이언트 토큰 원본으로 검증했습니다. 같은 ID라도 나중에 역할이 바뀐 `EX1_538t`는 처음 강화 효과와 사냥개 하수인을 구분하여 추가 검증 대상으로 유지합니다. 2013년 베타 3664에 실제 등록된 첫날 마법사 2개·드루이드 2개 덱과 원본 한국어 카드 자료를 교차 확인하여 수집 가능 카드 46개의 최초 사용일을 추가 검증했습니다. 해당 46개는 기존 한국 날짜 2013-08-17을 유지하고 증거·검증 상태만 변경했으며 이전 및 이후 밸런스 이력은 건드리지 않았습니다. 새로 검증한 부모 카드에서 생성·선택·변신 가능한 자식 9개(`EX1_160t`, `CS2_tk1`, `NEW1_026t`, `EX1_155a/b`, `EX1_160a/b`, `NEW1_008a/b`)도 당시 3664 원본 한국어 부모 효과와 자식 ID를 대조해 최초 실사용 한국 날짜 2013-08-17로 검증했습니다. 토큰의 후대 명칭·스탯을 최초 기록으로 소급하지 않았습니다. 기존에 검증된 첫날 부모 카드·기본 영웅 능력 12종에서 생성되는 자식 21개도 3664 한국어 원문과 동일한 아이디의 실제 생성 가능성을 확인하여 2013-08-17 실사용으로 검증했습니다. 현대 `EX1_finkle` 명칭은 초기 핑클 아인혼 표기와 구별하며 최초 이름·스탯의 완전 검증은 별개입니다. `EX1_116t`의 첫 사용일은 사용자 확인에 따라 2013-08-17로 복구했으나, 3664 당시 동일 네이티브 ID 직접 확인은 미완료여서 추정 상태를 유지합니다. 2013년 8월 16일(북미) 베타 중 작성된 커뮤니티 덱 빌더 기록과 3664 한국어 원본 카드 정의를 함께 확인하여 수집 가능 카드 176개의 최초 사용 가능일을 한국 시간 2013-08-17로 추가 검증했습니다. 커뮤니티 덱 작성은 실제 대전 로그와 다르므로 해당 증거 한계를 개별 메타데이터에 기록했으며 당시 기본 스탯이나 이후 밸런스 패치는 변경하지 않았습니다. 2013년 북미 베타 당일 덱 빌더의 실제 목록과 당시 한국어 원본 카드 ID가 일치하는 수집 가능 카드 21장의 2013-08-17 최초 사용을 추가 검증했습니다. 이미 검증된 첫날 부모 카드에서 실제 생성 가능한 자식 카드 17종도 초기 3664 ID와 효과를 대조하여 검증했습니다. 커뮤니티 덱 목록은 실전 대전 로그가 아니라는 한계를 개별 근거에 남겼습니다. 초기 2013-08-11 베타 안내 게시물의 수정 이력에서 악마 감지가 덱에 악마가 부족할 때 쓸모없는 임프(EX1_317t)를 생성한다는 설명을 추가로 확인하고, 첫날 실제 사용 가능한 부모 카드와 3664 한국어 자식 ID를 교차검증하여 2013-08-17 최초 사용일 검증을 완료했습니다. `EX1_116t`(새끼용, DBF 1912)는 사용자 확인에 따라 최초 날짜를 2013-08-17로 복구했습니다. 동일 3664 네이티브 ID 직접 확인이 남아 유일한 추정 ID로 둡니다(`ds1_whelptoken`은 DBF 54인 별도 ID). `EX1_538t`(사냥개, DBF 1715)는 개들을 풀어라가 변경된 4217 북미 베타 실사용일인 한국 2013-12-11에 소환 가능한 하수인으로 등장했으므로, 잘못된 2013-08-17의 강화 효과 시점을 삭제했습니다. 이전 '풀려남' 원본 클라이언트 기록은 메타데이터에 보존합니다. 설치된 최신 `nativeTags`를 과거에 소급하지 않습니다.

**호환성:** 플러그인 변경은 보류했습니다. 기존 세 주소에는 기존 소비자용 투영값을 생성하고, 정확한 신규 상태는 `-date` 출력에 분리합니다. 숫자 부재를 0으로 나타내는 등의 구형 한계는 호환 출력에만 남으며 원본에 소급하지 않습니다. 이번 변경의 범위는 API 자료 제공이며, 플러그인 설치·연결 주소 변경·실제 재가져오기·DB 변경은 수행하지 않습니다.

# Legacy card source data

The 609 JSON files in `source/Legacy/` retain the original Legacy.zip schema, metadata, versions, native tags and portrait references. `cards.json` contains the existing 282 Classic cards plus 327 missing cards, preserving API schema version 1 and all 282 original `art/` PNG files.

`Legacy.zip` has no source PNG/JPG artwork, 3D animations or golden video binaries, so no images were invented or falsely linked for the 327 new records. `art` is empty for those 327 records until original raster artwork becomes available. Historical details are preserved in the raw JSON here.
